# Лабораторная работа №6. Обработка двумерных массивов и контейнеров

## Описание

Изучение алгоритмов формирования и обработки двумерных массивов,
программирование и отладка программ формирования и обработки массивов
(статических и динамических) и контейнеров STL.

Задачи решаются по индивидуальному варианту; отдельные задания
переводятся на второй язык программирования согласно таблице 1.

## Задания

### Задание 1. Обработка двумерных массивов (вариант 8)

1. Матрица `M × N` (`M > 5, N > 5`), случайные числа в `[-50, 50]`.
   В каждой строке найти самую длинную строго возрастающую
   последовательность подряд идущих элементов. Определить номер строки
   с самой длинной такой последовательностью, скопировать её в
   одномерный динамический массив. Вывести номер строки, длину
   последовательности и сам массив.
2. Квадратная матрица `M × M` (`M > 5`), случайные числа в `[100, 200]`.
   Вычислить среднее арифметическое элементов чётных столбцов и
   среднее арифметическое элементов нечётных строк. Если первое больше —
   отсортировать главную диагональ по убыванию, иначе — по возрастанию.
   Вывести матрицу до и после сортировки диагонали.
3. Матрица символов `M × N` (`5 ≤ M, N ≤ 10`), случайные заглавные
   латинские буквы `'A'–'Z'` (или ручной ввод) и заданное слово.
   Определить, содержится ли слово в матрице: буквы берутся из
   последовательно смежных ячеек (по горизонтали/вертикали, без
   диагоналей), одна ячейка не используется дважды, поиск
   регистрозависимый. Вывести результат поиска.

### Задание 2. AES128 (CFB) — вариант 2

a) Реализовать шифрование AES128 (CFB) исходного текста;
b) реализовать расшифрование AES128 (CFB) обратно в исходный текст.

Дополнительно:
- вывести все сгенерированные ключи, промежуточные `State` и вектор
  инициализации (IV);
- реализовать генерацию случайного ключа и запись ключа в файл;
- поддержка русского и английского текста (UTF-8);
- текст кратен 16 байтам (при необходимости — PKCS7 Padding).

### Задание 3. СЛАУ — вариант 8

Из таблицы 3.1 выбрать данные `M, N, P` и решить систему

$$
\begin{cases}
M x_1 - 0.04 x_2 + 0.21 x_3 - 1.16 x_4 = -1.24,\\
0.25 x_1 - 1.23 x_2 + N x_3 - 0.09 x_4 = P,\\
-0.21 x_1 + N x_2 + 0.8 x_3 - 0.13 x_4 = 2.56,\\
0.15 x_1 - 1.31 x_2 + 0.06 x_3 + P x_4 = M
\end{cases}
$$

прямым (метод Гаусса с выбором главного элемента — чётные варианты)
и приближённым (метод простых итераций / Зейделя) методами с
точностью `ε = 10⁻³`. Вывести ход прямого и обратного хода, таблицу
итераций `n | x₁ | x₂ | x₃ | x₄ | εₙ`.

### Задание 4. Доска с монетами — вариант 2

Щит `N × M`, в каждой клетке `0` (орёл) или `1` (решка). За ход
выбирается пара соседних по стороне монет (по горизонтали или
вертикали) и обе переворачиваются. Найти минимальное число ходов,
чтобы получить рисунок **«рамка»**: все монеты по краям доски имеют
одно значение, все внутренние — другое.
